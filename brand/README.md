# 景熙 Lumyn · 智能光路

## 核心关系
符号来源于 Jing Xi（景熙）的拼音首字母 JX。“景熙”作为主字标，Lumyn 作为国际字标，共同出现在正式组合标志中。J 的弯折光路与 X 的交汇结构形成感知、连接、计算的联想。中心的留白代表光的穿行，呼应“景熙惟永，睿图载光”。这是设计表达，不表示模型性能或业务资质。

## 构形方法
1. 抽取：从 Jing Xi 提取 J / X 的弯折与交汇关系。
2. 简化：用宽笔画、少量曲线和一致的斜向切口构成基本模块。
3. 复制与镜像：四条交汇分支来自同一个路径，分别沿水平及垂直轴镜像，实际 SVG 通过 transform 复用几何。
4. 组合与光学校正：加入 J 光路，处理中心负形、连接位置与大小尺寸下的重心。

## 应用
标准色 #193F9C，纯色、无渐变。中文采用准确汉字轮廓，不依赖浏览设备的字体。英文为本项目绘制的几何路径。标志全部为可编辑原生 SVG，不是嵌入的生成位图。最小图形推荐 24px；小尺寸主组合标志使用场景应保证中文可读。四周留白建议不少于符号高度的 1/4。

官网的页眉、页脚、实验室、收尾品牌区与 favicon 已统一应用。公司业务内容不作修改。

## 概念探索
