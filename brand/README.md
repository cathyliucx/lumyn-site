# 景熙 · 日光印

图形以中文品牌为起点：「景」的日光、景象与远景，转化为日出之窗；「熙」底部的「灬」被抽象为从窗口伸出的四束光。四束光为汉字部件的抽象，不代表业务数量。横向留白形成地平线，呼应“景熙惟永，睿图载光”和 Enduring vision bears the light。

## 文件
- lumyn-symbol.svg：蓝色图形标
- lumyn-symbol-mono.svg：单色版本
- lumyn-symbol-reverse.svg：深色背景反白版本
- lumyn-logo.svg：图形与 Lumyn 字标的横向组合
- lumyn-logo-reverse.svg：横向组合反白版
- logo-presentation.svg：设计说明与应用展示

字标已转为轮廓，不依赖浏览者安装字体。SVG 图形背景透明，不使用渐变或位图。网站页眉、页脚、收尾品牌区、实验室及 favicon 已统一使用新标志。

## 用法
标准蓝 #184B9B；光束蓝 #5895EC。图形四周建议保留至少标志宽度的 1/6。图形最小建议宽度 24px；16px favicon 使用深蓝底版本。不要拉伸、旋转或添加发光效果。

## 设计过程
使用内置 image_gen 生成概念稿，再以原生 SVG 几何重绘和精修。最终图标不是嵌入的生成位图。

生成提示词要点：为景熙（Jingxi / Lumyn）设计原创蓝色公司标志；从景的日与熙的灬提取日光窗口和四束光，用负形融成一个紧凑印记；平面、少色、24px 可读；不使用眼睛、螺旋、神经网络或完整汉字。
